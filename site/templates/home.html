How it works

1

Rules while it writes

Skills for Claude Code and rules for Cursor teach the agent the patterns that lose funds: access control, reentrancy, unchecked calls, oracle manipulation, signature replay, missing signers, arbitrary CPIs.

2

A scan before every deploy

When the agent runs forge script --broadcast, hardhat … --network, anchor deploy or solana program deploy, the hook scans the project first: {{ruleCount}} built-in quick checks plus whichever analyzers you have installed.

3

A human decides

Local deploys run untouched. Testnet deploys with high findings ask you first. Mainnet deploys always ask, and are blocked when high findings remain. The agent gets the report and proposes fixes.

What it is, and isn't

  • A safety net for developers and their coding agents: pattern checks, open-source analyzers, and a human checkpoint before deploys.
  • Not an audit. Static analysis finds known bug classes; it can't prove a contract is safe. Get a professional audit before deploying code that will hold value.
  • Not a wallet, a token, a trading tool or financial advice. It never sees keys, signs or sends transactions, and sends nothing anywhere.
