# Security

Report vulnerabilities in Chain Preflight itself through GitHub's private vulnerability reporting on this
repository (Security → Report a vulnerability), not in a public issue.

In scope: anything that makes the pre-deploy hook approve or skip a deploy it should have stopped, run code
from a scanned project unexpectedly, or leak data. Wrong findings (false positives, missed bugs) are not
vulnerabilities: use the "False positive or missed bug" issue form.
